Moonveil Club is a small social prototype. The regulars, and the bodies you can wear, are KayKit Adventurers by Kay Lousberg, dedicated to the public domain under CC0 1.0. Ears, lute, wings, tusks, and the recolors are part of this game.

Accounts and saves stay in this browser. There is no server yet. The sign-in code is a small local adapter so a Firebase or Supabase one can replace it later.
