Credits

Moonveil Club is a small social prototype. The bodies are CC0 VRoid bases from the VRoid Project (pixiv), redistributed via OpenGameArt. Robes, hair, and ornaments are part of this game. Passwords never leave this browser.

Accounts and saves stay in this browser. There is no server yet. The sign-in code is a small local adapter so a Firebase or Supabase one can replace it later.
